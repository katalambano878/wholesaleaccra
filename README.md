# Accra Wholesale Clothing

> Female clothing & mannequins. Wholesale and retail with pickup or delivery in Accra.

## Getting Started

```bash
npm install
npm run dev
```

Dev server runs on port `3001`.

## Environment Variables

Copy `.env.example` to `.env.local` and fill in your own values. See `.env.example` for every variable the app reads.

## Stack

Next.js · React · Tailwind CSS · Supabase (Postgres + Auth + Storage) · Resend (email) · Moolre (mobile-money payments + SMS).
